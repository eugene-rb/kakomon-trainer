解答用紙を登録

解答用紙と解答解説をまとめて選ぶと、ファイル名から自動で対応付けます。複数の用紙を一度に登録できます。

用紙はPDF、解説・採点基準はPDF / Markdown / テキストに対応。

半角英数字の共通名に、役割を付けてください。
用紙：kyodai_english_2024_sheet.pdf
解答解説：kyodai_english_2024_answers.pdf
採点基準：kyodai_english_2024_rubric.pdf
共通名が一致する資料だけを組み合わせます（大文字・小文字は区別しません）。用紙だけの登録もできます。

詳細設定（通常は不要）

同名の用紙があっても、自動で別のIDを付けて登録します。

次の画面で解答欄と配点を設定します。登録後に作られる印刷用PDFを印刷して解答してください。
