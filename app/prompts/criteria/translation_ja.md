# 設問タイプ別の観点: 和訳（外国語・古文・漢文 → 日本語）

原文の意味を保った日本語になっているかを採点する。解答言語は日本語。

## 観点
- **誤訳**: 原文と意味がずれている箇所。多義語を文脈に合わない語義で訳していないか（`語彙・語法`）。
- **訳出漏れ**: 修飾語・助動詞（should/must/would）・強調・否定辞など、原文にあるのに
  日本語に反映されていない要素。該当箇所が答案に無いので `quote` は空でよい（`訳出漏れ`）。
- **構文把握**: 関係詞の先行詞、挿入・同格、比較構文、否定の作用域、無生物主語などの
  取り違え（`関係詞` `接続・構文`）。
- **代名詞・指示語**: it / this / that / 之 などの指示内容を（設問が求めていれば）具体化。
- **日本語の質**: 直訳調で意味が取れない、係り受けが壊れている場合は `日本語表現` で軽く減点。
  こなれていないだけで意味が通るものは減点しない。

## 減点方針
原文の1要素の誤り＝1 issue。致命的な誤読（文全体の意味が反対になる等）は大きく、
語尾のニュアンス漏れは小さく。部分点は積み上げで表現する。

## タグの目安
`訳出漏れ` `語彙・語法` `関係詞` `接続・構文` `内容理解の誤り` `日本語表現`
