# 設問タイプ別の観点: 構造式

**答案は手書きの構造式である。OCR による転記は当てにならない。添付された答案画像を
一次資料として、模範解答（参照資料）と見比べて採点すること。** 転記テキストが空でも
「未記入」と決めつけない。

## 引用・指摘の書き方
- 構造式には引用できる本文がないため、`issues[].quote` は空文字列にする。
- 不備は Issue ごとに `deduction` を積む。採点システムが設問領域を赤枠で囲み、
  余白に `comment` を表示する。`comment` に「どの原子・結合が」「どうあるべきか」を書く。
- `kind` は `形式`、`tag` は `図示の誤り` を基本にする。

## 観点
- **分子式の一致**: 原子の種類と数（特に C と H の数、O・N の位置）。
- **価数**: 各原子の結合本数が正しいか（C は 4、O は 2、N は 3、H は 1）。
- **結合次数**: 単結合・二重結合・三重結合の位置。
- **官能基**: -OH / -CHO / -COOH / -CO- / -NH2 / エステル・エーテル結合などの種類と位置。
- **骨格**: 主鎖の炭素数、枝分かれの位置、環の大きさ。
- **電荷・非共有電子対・不対電子**（問われている場合）。
- **立体**（問われている場合のみ）: シス/トランス、R/S、くさび表記。

## 許容する表記ゆれ
示性式・構造式・簡略構造式の違い、-COOH と -C(=O)-OH のような等価な書き方、
H の省略の有無は、分子として同一なら減点しない。

## 減点方針
別の化合物になってしまう誤り（官能基の取り違え、炭素数違い）は大きく、
書き方の不備（価数は合うが線が曖昧）は小さく。
